# Altcast IPTV - releases

Download files for Altcast IPTV (Fire TV / Android TV).

**Fire TV (Downloader app):** enter
```
https://github.com/fmykey/altcast-iptv-releases/releases/latest/download/Altcast-IPTV.apk
```

Installed apps update themselves from the latest release (`update.json`).
